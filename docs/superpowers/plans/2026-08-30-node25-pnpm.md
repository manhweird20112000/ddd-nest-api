# Node 25 Pnpm Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use inline execution for this compact infrastructure migration. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the template to pnpm on Node 25.

**Architecture:** Keep the existing NestJS scripts and Docker shape, changing only the package manager and Node base image. Use the existing `pnpm-lock.yaml` as the single lockfile.

**Tech Stack:** Node.js 25, pnpm 11.24.0, Docker, Docker Compose, NestJS.

## Global Constraints

- Use `node:25-alpine` in every Docker stage.
- Use pnpm commands in Docker and docs.
- Keep `pnpm-lock.yaml` as the only package lockfile.
- Do not change application behavior.
